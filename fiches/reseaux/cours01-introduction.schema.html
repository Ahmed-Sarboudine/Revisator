À l'envoi, sur le serveur web (on descend)

  1. Application : la page HTML est fournie par HTTP.
  2. Transport : découpée en segments TCP, chacun avec les ports (80 → port du client).
  3. Internet : chaque segment devient un paquet avec les IP du serveur et du client.
  4. Accès réseau : chaque paquet devient une trame avec les MAC et la queue FCS, puis la carte réseau l'envoie en bits sur le câble.

À la réception, sur le client (on remonte)

  1. Accès réseau : les bits redeviennent une trame ; si la MAC de destination est la sienne, il retire en-tête et queue → paquet.
  2. Internet : il retire l'en-tête IP → segment.
  3. Transport : il retire l'en-tête TCP et réassemble les segments dans l'ordre → données.
  4. Application : le navigateur affiche la page.

Quelle adresse sert à quoi ?

PortQuelle application sur la machine (80 = web, 25 = mail…)
IPQuelle machine sur Internet, de la source à la destination finale
MACQuelle carte réseau sur le réseau local, d'un équipement au suivant
