Courbes de Bézier

TP 4 : consignes et squelette tkinter
(polynômes de Bernstein)

À retenir en priorité
  • Une courbe de Bézier est définie par des points de contrôle $P_0, \dots, P_n$. Elle part de $P_0$ et arrive en $P_n$, mais ne passe pas en général par les points intermédiaires : elle en est seulement attirée. Ce n'est pas une interpolation.
  • Polynôme de Bernstein : $B_{n,i}(t) = \binom{n}{i}\, t^i (1-t)^{n-i}$, pour $t \in [0, 1]$.
  • Courbe : $\displaystyle P(t) = \sum_{i=0}^{n} B_{n,i}(t)\, P_i$, à appliquer séparément aux $x$ et aux $y$.
  • $n + 1$ points de contrôle ⇒ courbe de degré $n$.

1. Propriétés utiles

  • $\sum_i B_{n,i}(t) = (t + (1-t))^n = 1$ : $P(t)$ est une moyenne pondérée des points de contrôle, donc la courbe reste dans leur enveloppe convexe.
  • $t = 0$ : seul $B_{n,0}(0) = 1$, donc $P(0) = P_0$. $t = 1$ : $P(1) = P_n$.
  • La courbe est tangente au segment $[P_0P_1]$ au départ et à $[P_{n-1}P_n]$ à l'arrivée.
  • Déplacer un point de contrôle modifie toute la courbe (contrôle global).
Cas $n = 2$ (3 points) $$P(t) = (1-t)^2P_0 + 2t(1-t)P_1 + t^2P_2$$ Cas $n = 3$ (4 points) $$P(t) = (1-t)^3P_0 + 3t(1-t)^2P_1 + 3t^2(1-t)P_2 + t^3P_3$$ Exemple : $P_0 = (0, 0)$, $P_1 = (1, 2)$, $P_2 = (2, 0)$ ; en $t = \frac12$ : $P = \frac14(0,0) + \frac12(1,2) + \frac14(2,0) = (1, 1)$ : la courbe ne monte qu'à mi-hauteur de $P_1$.

2. Le TP 4 (tkinter)

def bernstein(n, i, t):
    return math.comb(n, i) * t**i * (1 - t)**(n - i)

def calculer_courbe_bezier(points, resolution=150):
    n = len(points) - 1
    if n < 1:
        return []
    coords = []
    for j in range(resolution + 1):   # t de 0 à 1 inclus
        t = j / resolution
        x = sum(bernstein(n, i, t) * points[i][0] for i in range(n + 1))
        y = sum(bernstein(n, i, t) * points[i][1] for i in range(n + 1))
        coords.extend([x, y])
    return coords
  • resolution = 150 est le nombre de segments : il faut donc 151 valeurs de $t$ (d'où resolution + 1), sinon la courbe n'atteint pas $P_n$.
