Interpolation d'Hermite

Intro et TD « Hermite » (novembre), TP 5
(base $\varphi_1, \dots, \varphi_4$, polynômes par morceaux)

À retenir en priorité
  • On connaît en chaque point la valeur $y_i$ et la dérivée $v_i$ (la pente de la tangente). Sur chaque intervalle $[x_i, x_{i+1}]$, on cherche un polynôme de degré 3 : 4 contraintes (2 valeurs, 2 dérivées) pour 4 coefficients.
  • Sur $[0, 1]$, la base d'Hermite est faite pour que chaque $\varphi$ « porte » une seule contrainte : $P(t) = y_0\varphi_1(t) + y_1\varphi_2(t) + v_0\varphi_3(t) + v_1\varphi_4(t)$.
  • Cas général sur $[x_A, x_B]$ : poser $d = x_B - x_A$ et $t = \dfrac{x - x_A}{d}$, puis $P(x) = y_A\varphi_1(t) + y_B\varphi_2(t) + d\,\big[v_A\varphi_3(t) + v_B\varphi_4(t)\big]$.
  • Le facteur $d$ devant les dérivées vient de $\frac{dt}{dx} = \frac1d$. L'oublier est l'erreur la plus fréquente.

Retrouver $\varphi_1$ (méthode « stylée » du prof)
  • $\varphi_1(1) = \varphi_1'(1) = 0$ : 1 est racine double, donc $\varphi_1(t) = (at + b)(t-1)^2$.
  • $\varphi_1(0) = 1$ donne $b = 1$.
  • $\varphi_1'(t) = a(t-1)^2 + 2(at+b)(t-1)$ ; $\varphi_1'(0) = a - 2b = 0$ donne $a = 2$.
  • D'où $\varphi_1(t) = (2t+1)(t-1)^2$.

Même idée pour les autres : $\varphi_2$ et $\varphi_4$ ont 0 comme racine double (facteur $t^2$) ; $\varphi_3$ a 0 racine simple et 1 racine double.

2. Cas général : se ramener à $[0, 1]$

Pour $x \in [x_A, x_B]$, $t = \frac{x - x_A}{x_B - x_A}$ va de 0 à 1. On cherche $P(x) = a\varphi_1(t) + b\varphi_2(t) + c\varphi_3(t) + d'\varphi_4(t)$ :

  • $x = x_A$ ($t = 0$) : $P(x_A) = a = y_A$ ; $x = x_B$ ($t = 1$) : $b = y_B$.
  • $P'(x) = \big[a\varphi_1'(t) + \dots\big]\cdot\frac{dt}{dx}$ avec $\frac{dt}{dx} = \frac{1}{x_B - x_A}$, donc $P'(x_A) = \frac{c}{x_B - x_A} = v_A$ : $c = (x_B - x_A)\,v_A$, et de même $d' = (x_B - x_A)\,v_B$.
Exemple du cours : $x = 1, 5$ ; $y = 6, 2$ ; $v = \frac32, -3$. $d = 4$, $t = \frac{x-1}{4}$ : $$P_1(x) = 6\varphi_1(t) + 2\varphi_2(t) + 4\left[\tfrac32\varphi_3(t) - 3\varphi_4(t)\right]$$ Partiel 2025, segment [BC] : $B(-1; 4)$, $v_B = 7$ ; $C(3; 5)$, $v_C = -4$. $d = 3 - (-1) = 4$, $t = \frac{x+1}{4}$ : $$P(x) = 4\varphi_1(t) + 5\varphi_2(t) + 4\left[7\varphi_3(t) - 4\varphi_4(t)\right]$$

3. Plusieurs points : polynôme par morceaux (TP 5)

Avec $n$ points, il y a $n - 1$ intervalles, donc $n - 1$ polynômes $P_i$. Comme les $\varphi$ sont nulles en dehors de $[0, 1]$, on peut écrire $P = P_1 + P_2 + \dots$ : pour un $x$ donné, seul le morceau qui le contient est non nul.

def phi1(t):
    if 0 <= t <= 1:
        return (t - 1)**2 * (1 + 2*t)
    return 0
# idem phi2, phi3, phi4

def foncHermite(X, Y, V, x):
    S = 0
    for i in range(len(X) - 1):
        d = X[i+1] - X[i]
        t = (x - X[i]) / d
        S += (Y[i]*phi1(t) + Y[i+1]*phi2(t)
              + d*(V[i]*phi3(t) + V[i+1]*phi4(t)))
    return S
Pièges
  • Oublier le facteur $d$ devant $v_A\varphi_3 + v_B\varphi_4$ (sauf si $d = 1$).
  • Inverser les rôles : $\varphi_1$, $\varphi_2$ portent les valeurs, $\varphi_3$, $\varphi_4$ les dérivées.
  • Avec 0 <= t <= 1 des deux côtés, un nœud intérieur appartient à deux morceaux : la somme y vaut $2y_i$. Prendre 0 <= t < 1 (et inclure $t = 1$ pour le dernier morceau) ou n'évaluer que le bon morceau.
Tracer les tangentes La tangente en $(x_k, y_k)$ a pour équation $y = v_k(x - x_k) + y_k$. On trace un petit segment de $x_k - 1$ à $x_k + 1$ :
