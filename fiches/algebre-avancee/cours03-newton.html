Base de Newton et différences divisées

Visio du 14 octobre et TP 3
(système triangulaire, ajout d'un point)

À retenir en priorité
  • Base de Newton : $N_0 = 1$, $N_1 = (x - x_0)$, $N_2 = (x - x_0)(x - x_1)$, …, $N_k = N_{k-1} \cdot (x - x_{k-1})$. Le dernier point $x_n$ n'apparaît jamais dans la base.
  • On cherche $P(x) = a_0 + a_1N_1(x) + \dots + a_nN_n(x)$. Les contraintes forment un système triangulaire : $a_0 = y_0$, puis $a_1$, puis $a_2$…
  • Les coefficients se lisent sur la diagonale du tableau des différences divisées.
  • Avantage : ajouter un point ne change pas les coefficients déjà calculés. On ajoute un seul terme $a_{n+1}N_{n+1}$.

1. Pourquoi le système est triangulaire

$N_k(x_i) = 0$ dès que $i < k$ (le produit contient le facteur $x_i - x_i$). Exemple du cours : $x = 1, 2, 3$ et $y = -4, 5, -2$.

$$\begin{cases} P(1) = a_0 = -4 \\ P(2) = a_0 + a_1(2-1) = 5 \\ P(3) = a_0 + a_1(3-1) + a_2(3-1)(3-2) = -2 \end{cases}$$

On résout de haut en bas : $a_0 = -4$, $a_1 = 9$, $a_2 = -8$, donc

$$P(x) = -4 + 9(x-1) - 8(x-1)(x-2).$$
Différences divisées (forme classique)

$f[x_i] = y_i$, puis chaque colonne divise la différence de deux voisins par l'écart de leurs abscisses extrêmes :

$$f[x_i, \dots, x_{i+k}] = \frac{f[x_{i+1}, \dots, x_{i+k}] - f[x_i, \dots, x_{i+k-1}]}{x_{i+k} - x_i}$$

Les coefficients sont $a_k = f[x_0, \dots, x_k]$ : le haut de chaque colonne.

2. Le tableau du prof (méthode du « pivot »)

Le prof calcule colonne par colonne en divisant toujours par rapport au point de référence de la colonne (le premier point non encore utilisé) : $z_k \leftarrow \dfrac{z_k - z_{\text{ref}}}{x_k - x_{\text{ref}}}$ pour tous les $k$ au-dessous de la référence. Les coefficients sont entourés sur la diagonale. Les deux méthodes donnent les mêmes coefficients.

Exemple du cours : $x = -1, 1, 3, 2$ et $y = -7, 5, 1, 10$.

Pièges
  • Au partiel, la base est numérotée à partir de 1 : $N_1 = 1$, $N_2 = x + 1$, $N_3 = (x+1)x$, $N_4 = (x+1)x(x-1)$. Dans le cours, à partir de 0. Lire l'énoncé.
  • Garder l'ordre de la grille donné, même si les $x_i$ ne sont pas triés (exemple $-1, 1, 3, 2$).
  • Le dénominateur utilise les abscisses, jamais les ordonnées. Bien écrire $x - (-1) = x + 1$.

3. Côté TP (Python)

def dif_divis(X, Y):
    Z = list(Y)                    # copie de Y
    n = len(Z)
    for ref in range(n - 1):
        for k in range(ref + 1, n):
            Z[k] = (Z[k] - Z[ref]) / (X[k] - X[ref])
    return Z                       # coefficients a_0 … a_n

def polyfin(X, Z, x):              # Σ Z[k]·N_k(x)
    S, N = Z[0], 1
    for k in range(1, len(Z)):
        N = N * (x - X[k - 1])     # N_k = N_{k-1}·(x − x_{k−1})
        S += Z[k] * N
    return S
  • $Z$ est modifié sur place : à la fin, $Z[k]$ contient $a_k$.
  • Version « pas stylée » : recalculer chaque $N_k$ par un produit complet. Version « sensée » : mettre $N$ à jour à chaque tour, comme ci-contre.
Ajouter un point $(\alpha, \beta)$

$P_{\text{nouveau}} = P_{\text{ancien}} + c\,N_{n+1}$ avec $N_{n+1}(x) = \prod_{k=0}^{n}(x - x_k)$. On impose $P_{\text{nouveau}}(\alpha) = \beta$ :

$$c = \frac{\beta - P_{\text{ancien}}(\alpha)}{N_{n+1}(\alpha)}$$

Puis Z.append(c), X.append(α), Y.append(β). Aucun autre coefficient ne change.
