Base de Lagrange

Visio du 7 octobre et TP 2
(polynômes $L_i$, phénomène de Runge)

À retenir en priorité
  • Pourquoi changer de base : dans la base canonique, il faut construire et inverser $V$. Dans la base de Lagrange, il n'y a aucun système à résoudre.
  • $L_i$ vaut 1 en $x_i$ et 0 en tous les autres $x_k$ : $\displaystyle L_i(x) = \prod_{k \ne i} \frac{x - x_k}{x_i - x_k}$
  • Les coefficients sont directement les ordonnées : $\displaystyle P(x) = \sum_{i=0}^{n} y_i\, L_i(x)$
  • Avec $n+1$ points, chaque $L_i$ est de degré $n$, donc $P$ aussi (au plus).

1. Construire un $L_i$ (méthode du prof)

Tableau de définition : $L_i$ vaut 1 sur sa colonne, 0 ailleurs.

$x_0 = 1$$x_1 = 2$$x_2 = 3$
$L_0$100
$L_1$010
$L_2$001
  1. $L_0$ s'annule en 2 et en 3, donc $L_0(x) = \alpha (x-2)(x-3)$.
  2. $L_0(1) = 1$ donne $\alpha (1-2)(1-3) = 1$, soit $\alpha = \frac{1}{(1-2)(1-3)}$.
  3. D'où $L_0(x) = \dfrac{(x-2)(x-3)}{(1-2)(1-3)}$.
Recette pour $L_i$
  • Numérateur : produit des $(x - x_k)$ pour tous les points sauf $x_i$.
  • Dénominateur : le même produit où l'on remplace $x$ par $x_i$.
  • Calculer le dénominateur en nombre (attention aux signes).
Exemple du cours : $x = 1, 2, 3$ et $y = -7, 5, 4$. $$P(x) = -7\,\frac{(x-2)(x-3)}{(1-2)(1-3)} + 5\,\frac{(x-1)(x-3)}{(2-1)(2-3)} + 4\,\frac{(x-1)(x-2)}{(3-1)(3-2)}$$ Vérification : $P(1) = -7 \times 1 + 5 \times 0 + 4 \times 0 = -7$ ✓.
Exemple du partiel 2025 : $x = -1, 1, 2, 3$ et $y = -3, 1, 3, 4$. $$L_1 = \frac{(x-1)(x-2)(x-3)}{(-2)(-3)(-4)} = -\frac{(x-1)(x-2)(x-3)}{24} \qquad L_2 = \frac{(x+1)(x-2)(x-3)}{(2)(-1)(-2)} = \frac{(x+1)(x-2)(x-3)}{4}$$ $$L_3 = \frac{(x+1)(x-1)(x-3)}{(3)(1)(-1)} = -\frac{(x+1)(x-1)(x-3)}{3} \qquad L_4 = \frac{(x+1)(x-1)(x-2)}{(4)(2)(1)} = \frac{(x+1)(x-1)(x-2)}{8}$$ $$P(x) = -3L_1(x) + L_2(x) + 3L_3(x) + 4L_4(x)$$ Le partiel numérote les points à partir de 1 ($L_1$ à $L_4$) ; le cours, à partir de 0. Seul compte de bien associer chaque $L$ à son point.

2. Côté TP (Python)

def lagrange(X, i, x):        # renvoie L_i(x)
    res = 1
    for k in range(len(X)):
        if k != i:
            res *= (x - X[k]) / (X[i] - X[k])
    return res

def polyfin(X, Y, x):          # P(x) = Σ y_i L_i(x)
    return sum(Y[k] * lagrange(X, k, x)
               for k in range(len(X)))
  • La condition k != i évite la division par $x_i - x_i = 0$.
  • Tester avec $f = \sin$ (ça marche bien), puis avec $f(x) = \dfrac{1}{1 + 8x^2}$ (ou $\frac{1}{1+10x^2}$) sur $[-4, 4]$ ou $[-5, 5]$.
  • Inconvénient : ajouter un point change tous les $L_i$, il faut tout recalculer. La base de Newton corrige ce défaut.

3. Phénomène de Runge

Avec des points équidistants (np.linspace) et $f(x) = \frac{1}{1+8x^2}$, le polynôme d'interpolation colle à $f$ au centre mais oscille de plus en plus fort aux bords quand $n$ augmente. Augmenter $n$ aggrave l'erreur au lieu de la réduire.

Ce n'est pas un bug de code : c'est une propriété de l'interpolation polynomiale de haut degré sur une grille régulière.

Remède : plus de points sur les bords
  • Points de Tchebychev : $x_k = \cos\!\left(\frac{(2k+1)\pi}{2(n+1)}\right)$ (ramenés sur $[a, b]$), naturellement resserrés aux extrémités.
  • Version « à la main » du cours : mettre par exemple 40 % des points sur chaque bord et 20 % au centre ($X = X_1 \cup X_2 \cup X_3$).
  • Ou changer d'outil : polynômes par morceaux (Hermite, splines), de petit degré sur chaque intervalle.
