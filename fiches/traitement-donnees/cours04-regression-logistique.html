Régression logistique

Métriques de classification, modèle logistique,
régularisation, multi-classes, déséquilibre et seuil

À retenir en priorité
  • Un classifieur calcule un score (idéalement une probabilité π(x) = P(Y = 1 | x)), puis une règle de décision : ŷ = 1 si π > seuil.
  • Seuil 0,5 = minimum d'erreurs si la probabilité est juste (calibrée) et si les deux erreurs ont le même coût.
  • Toujours comparer l'accuracy au classifieur naïf (classe majoritaire) et regarder au moins deux indicateurs.
  • Modèle : log(π / (1 − π)) = μ0 + μ1x1 + … ⇔ π = σ(z) = 1 / (1 + e−z). Frontière = hyperplan : modèle linéaire.
  • Apprentissage = maximum de vraisemblance = minimiser l'entropie croisée. Convexe, sans formule : descente de gradient ∇g = XT(π − y)/P.
  • eμj multiplie la cote (pas la probabilité) quand xj augmente de 1, les autres fixées.
  • Classe rare : l'AUC peut être bonne et aucune probabilité > 0,5 ⇒ déplacer le seuil (choisi par validation croisée). class_weight="balanced" ≈ décaler μ0 et fausse les probabilités.

1. Classification : le cadre

  • Binaire (2 classes), multi-classes (K > 2, classes disjointes), multi-label (plusieurs étiquettes à la fois, non traité).
  • Classe positive (1) = celle qu'on veut détecter, souvent la plus rare.
  • Probabilités : P(Y = k | x) ≥ 0 et Σk = 1.
  • Calibrée : parmi les exemples notés ≈ 0,8, environ 80 % de positifs (diagramme de calibration sur la diagonale).

  • accuracy = q1·rappel + q0·spécificité : pondérée par la taille des classes.
  • F1 : moyenne harmonique, tirée vers la plus petite (préc. 1, rappel 0,1 ⇒ F1 ≈ 0,18).
  • classification_report : une ligne par classe ; dans la ligne négative, le rappel = spécificité ; macro (rappel macro = accuracy équilibrée) / weighted (rappel weighted = accuracy) ; support = effectif de la vraie classe.
  • Courbe ROC : rappel en fonction du taux de FP, pour tous les seuils. AUC = P(score d'un positif > score d'un négatif) ; 0,5 = hasard. Ne dépend que de l'ordre des scores et pas des proportions.
  • Courbe précision-rappel, résumée par la précision moyenne (AP) ; hasard = q1. Plus parlante quand la classe positive est rare.
  • Entropie croisée (log loss) : moyenne de −log(proba de la vraie classe). 0,99 → 0,01 ; 0,5 → 0,69 ; 0,01 → 4,6. Seule métrique qui juge la justesse des probabilités.
Un indicateur seul se triche« Toujours positif » : rappel 1, spécificité 0. « Positif seulement au-delà de 1,90 m » : précision 1, rappel 0,02. Quand le seuil monte, le rappel baisse et la spécificité monte. Choisir un seuil, c'est apprendre : on évalue sur d'autres données.

3. Le modèle logistique

  • La régression linéaire sur y ∈ {0, 1} sort de [0, 1] et ne suit pas la forme en S.
  • Cote = π / (1 − π) (3 = « 3 contre 1 », π = 0,75) ; log-cote (logit) de −∞ à +∞, 0 pour π = 0,5.
  • Hypothèses : Y | x suit une Bernoulli(π(x)), exemples indépendants ; la log-cote est affine en x.
  • Frontière (π = 1/2) : μ0 + μ1x = 0 ⇔ x = −μ0/μ1 (taille : 166,5 cm).
  • μ0 déplace la sigmoïde ; |μ1| règle sa raideur ; signe de μ1 = sens.
  • Deux classes gaussiennes de même écart-type ⇒ log-cote exactement affine.
Apprendre et prédire

g(μ) = −(1/P) Σ [ yi log πi + (1 − yi) log(1 − πi) ]

  • Convexe, pas d'équations normales : itératif (gradient du TD 1, lbfgs).
  • predict_proba (colonne 1 = π), predict (seuil 1/2), decision_function (log-cote).
  • LogisticRegression() est régularisée par défaut (L2, C=1) ; C=np.inf pour l'enlever.
  • Avec une seule variable, l'AUC = celle de la variable (même ordre) : le modèle ne fait que choisir un seuil.

4. Interpréter les coefficients

  • Taille : μ1 = 0,2865/cm ⇒ eμ1 ≈ 1,33 : chaque cm multiplie la cote par 1,33 (10 cm : × 17,5). L'effet sur la probabilité dépend de la position sur la sigmoïde.
  • Sur variables standardisées, eμj = effet d'un écart-type : coefficients comparables.
  • Colinéarité : à autres mesures fixées, un poids élevé évoque une femme (coefficient négatif alors que les hommes sont plus lourds). Le sucre résiduel des vins dépend de la présence de la densité dans le modèle.
  • Corrélation n'est pas causalité (alcool et qualité du vin).

5. Séparation parfaite et régularisation

Avec les 93 mesures d'ANSUR, les classes sont parfaitement séparables : multiplier μ par 10 ne bouge pas la frontière mais rapproche la vraisemblance de 1. Pas de maximum de vraisemblance : coefficients arbitraires (selon l'arrêt de l'algorithme), probabilités trop confiantes.

Remède : pénaliser (L2 comme Ridge, L1 comme Lasso). C = 1/λ : C petit = régularisation forte. l1_ratio=1 + solver="liblinear" pour L1, qui garde peu de variables (9 variables, 99,7 % pour C = 0,01). Standardiser avant.

6. Plus de deux classes : softmax

P(Y = k | x) = ezk / Σl ezl, zk = μk,0 + μk,1x1 + …

Un score affine par classe ; probabilités positives de somme 1. Pour K = 2, on retrouve σ(z1 − z0). Vins en 3 classes : accuracy ≈ 0,57 (naïf ≈ 0,45), erreurs surtout entre classes voisines, classe rare « excellent » mal reconnue.

7. Déséquilibre et seuil

  • Vins « note ≥ 8 » (3 %) : accuracy 97 % = naïf, rappel 0. Probabilité max 0,36 : rien ne dépasse 0,5. Pourtant AUC ≈ 0,79 : le modèle classe bien, le seuil ne convient pas.
  • ROC trop optimiste quand la classe est rare ; préférer précision-rappel.
  • Le seuil est un hyperparamètre : le choisir sur des prédictions de validation croisée (cross_val_predict, StratifiedKFold), jamais sur le test.
  • Seuil maximisant l'accuracy équilibrée ≈ q1 (0,03) : présélection (rappel 0,63, précision 0,07). Seuil du F1 (0,095) : compromis.
Rééquilibrer = déplacer μ0

log-cote = log(f1/f0) + log(q1/q0)

Changer les proportions ne change que le 2e terme : μ̃0 = μ0 + log(q̃1/q̃0) − log(q1/q0).

  • Rééquilibré au seuil 1/2 ≈ original au seuil q1.
  • AUC inchangée, probabilités faussées (moyenne 0,31 au lieu de 0,03).
  • Utile si les proportions d'apprentissage ≠ réalité (cas-témoins : corriger μ0), données trop nombreuses, outil imposant 0,5.
  • ANSUR (67 % d'hommes) → population à 50 % : μ0 − 0,72 ; 1,70 m : 73 % → 57 %.
