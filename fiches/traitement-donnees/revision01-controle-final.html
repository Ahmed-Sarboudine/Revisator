L'épreuve
  • Écrit de 1 h 30, sur papier. Aucune calculatrice, aucun document, aucun appareil : les calculs se font de tête, sur des nombres simples.
  • Surtout un QCM corrigé par machine, plus deux courtes questions ouvertes.
  • Une page de ressources au début du sujet : figures et tableaux, et un formulaire (matrice de confusion, accuracy, précision, rappel, spécificité). Inutile de les apprendre par cœur : il faut savoir les lire.
  • Pas besoin de tout traiter pour avoir 20/20 : le seuil est fixé après la correction.
  • Ni démonstration, ni formule d'algorithme, ni syntaxe Python : le code n'apparaît qu'en courts extraits à lire.
Consignes du jour (copie lue par machine)
  • Stylo bleu ou noir et blanco. Pas de crayon à papier.
  • Tout se reporte sur la feuille de réponses à la fin du sujet ; le reste n'est pas corrigé.
  • Colorier entièrement chaque case (pas de croix, de coche ni de rond). Erreur : blanco sur la case, sans redessiner le contour.
  • Questions ♣ : plusieurs bonnes réponses possibles ; chaque mauvaise case retire des points (jamais moins de 0 par question). Les autres : une seule bonne réponse.
  • Rendre le sujet complet et la feuille. Une consigne non respectée qui oblige à corriger à la main peut coûter des points.
Ce qui est évalué

Cours 1 à 5 et TD 1 à 4, en privilégiant ce qui a été vu à la fois en cours et en TD. Le contrôle vérifie que vous comprenez les fondamentaux :

  • à quoi sert chaque méthode, et sur quelles hypothèses elle repose ;
  • quelle méthode choisir dans une situation donnée ;
  • comment lire une métrique ou une figure, et quels pièges éviter.

2. Le formulaire (donné) et comment le lire

prédit négatifprédit positif
vrai négatifVNFP
vrai positifFNVP
  • accuracy = (VP + VN) / total : à comparer au classifieur naïf (proportion de la classe majoritaire).
  • précision = VP / (VP + FP) : parmi les déclarés positifs, la part vraiment positive (colonne).
  • rappel = VP / (VP + FN) : parmi les vrais positifs, la part détectée (ligne).
  • spécificité = VN / (VN + FP) : parmi les vrais négatifs, la part reconnue (ligne).
Calcul type (de tête)
1 000 SMS : 120 spams, 880 légitimes ; VP = 90, FN = 30, FP = 10, VN = 870.
précision = 90/100 = 0,90 · rappel = 90/120 = 0,75
accuracy = 960/1 000 = 0,96 · naïf « tout légitime » = 0,88
spécificité = 870/880 ≈ 0,99

Réflexes : FN = « positif raté » ; le dénominateur du rappel est le nombre de vrais positifs (une ligne), celui de la précision le nombre de déclarés positifs (une colonne).

3. Les pièges qui reviennent

  • Accuracy et classe rare : 97 % peut être le score du classifieur naïf (rappel nul). Regarder le rappel de la classe rare.
  • Seuil : 0,5 n'est optimal que si les probabilités sont justes et les erreurs de même coût. Baisser le seuil : rappel ↑, faux positifs ↑, spécificité ↓.
  • Courbe ROC : un point = un seuil ; (0, 1) = parfait ; diagonale = hasard ; ne dépend que de l'ordre des scores.
  • Validation vs test : choisir (hyperparamètres, seuil, modèle) sur la validation ou par validation croisée ; le test une seule fois à la fin.
  • Sur-apprentissage : très bon en apprentissage, mauvais en validation (R² peut être négatif). Sous-apprentissage : mauvais partout.
  • Rééquilibrer (class_weight) ≈ déplacer le seuil, fausse les probabilités.
  • Fuite d'information : variable indisponible au moment de prédire (Queriest le lundi), colonne calculée à partir de la cible (sel/sodium), dictionnaire appris avec le test.
  • Doublons : tout ce qui est lié reste du même côté du découpage (en apprentissage).
  • Séries temporelles : découper par date, décaler avant de découper, battre une référence naïve.
  • Résidus structurés ⇒ variable oubliée ou mauvaise forme ; on ne supprime pas les points qui gênent.
  • Colinéarité : bon R², coefficients instables. Corrélation nulle ≠ absence de lien (seulement pas de lien linéaire).
  • KNN : standardiser ; se dégrade en grande dimension ; n'extrapole pas.
  • Génératif : vaut ce que vaut la loi choisie ; Bayes naïf trop sûr de lui si variables corrélées ; QDA gourmande en exemples.
Questions ouvertes : la démarche à rédiger Situer le problème (régression ou classification, classes déséquilibrées ?) → dire ce qui ne va pas dans le résultat proposé, avec la métrique adaptée et la référence naïve → proposer la correction (seuil, variables disponibles, logarithme, régularisation, loi mieux choisie…) → préciser sur quelles données on fait les choix (validation, validation croisée) et comment on évalue (test, une fois).
