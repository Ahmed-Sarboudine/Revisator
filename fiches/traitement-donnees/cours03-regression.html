Régression

Indicateurs et visualisation, données Ciqual,
régression linéaire, Ridge / Lasso, k plus proches voisins

À retenir en priorité
  • Médiane = quantile à 50 % : robuste. La moyenne ne l'est pas (une valeur aberrante peut la doubler). Même chose pour écart interquartile (robuste) / écart type (non).
  • Corrélation ρ = Cov(X,Y) / (σXσY) : sans unité, entre −1 et 1, ne mesure qu'un lien linéaire, n'implique pas de causalité. Toujours tracer les données (Anscombe).
  • Évaluer : MSE (critère minimisé, unité²), RMSE et MAE (unité de y), R² = 1 − MSE / Var(Y) (0 = moyenne, < 0 = pire que la moyenne). La SSE ne se compare pas d'une base à l'autre.
  • Moindres carrés : simple μ1 = Cov(X,Y)/Var(X), μ0 = ȳ − μ1x̄ ; multiple μ* = (XTX)−1XTy (équations normales).
  • Colinéarité : bon R² mais coefficients instables et non interprétables. Elle peut échapper à la matrice de corrélation (multicolinéarité).
  • Ridge (‖μ‖²) stabilise ; Lasso (‖μ‖1) met des coefficients à zéro (sélection). Standardiser avant.
  • KNN : non paramétrique, moyenne des K voisins. Standardiser, n'extrapole pas, coûteux en mémoire et en prédiction.

2. Préparer des données réelles : Ciqual (notebook 2)

  • Une colonne pandas n'a qu'un type : virgules décimales et valeurs -, traces, < 0,5 ⇒ tout est lu en texte.
  • Convention : - → manquant, traces → 0, < x → x/2. Ignorer les valeurs censurées surestime la moyenne (on garde les plus riches).
  • Retirer les « aliments moyens » (calculés à partir d'autres lignes).
  • Colonnes calculées (kJ/kcal, sel = 2,5 × sodium) : prédire l'une avec l'autre = fuite de données.
  • Contrôle de cohérence : les constituants principaux somment à 100 g ; d'où eau ≈ 100 − autres (erreur < 1 g).
  • On ne supprime un point extrême que si c'est une erreur ou s'il sort du domaine (une huile à 100 g de lipides est vraie).

L'eau, facteur de confusion : un aliment aqueux est pauvre en tout. Sur matière sèche, la corrélation glucides/énergie change de signe.

4. Régression linéaire

Simple : y = μ0 + μ1x

μ1 = Cov(X,Y) / Var(X) · μ0 = ȳ − μ1x̄

  • Critère convexe ⇒ minimum global unique.
  • Sur l'apprentissage : R² = ρ².
  • Pente = accroissement moyen de y quand x augmente de 1 (énergie : ≈ 37 kJ par g de lipides).
  • scikit-learn : LinearRegression().fit(X, y), X de forme (P, N) ; intercept_, coef_, score = R².

Multiple

XTX μ = XTy ⇒ μ* = (XTX)−1XTy

X a une colonne de 1. Inversible si colonnes linéairement indépendantes. En pratique np.linalg.solve.

Le fil rouge : retrouver la formule de l'énergie
Lipides seuls : R² test 0,73, RMSE ≈ 390 kJ.
+ glucides + protéines + fibres, alcool, polyols, acides organiques : R² > 0,999, RMSE < 10 kJ.
Coefficients ≈ facteurs du règlement UE : 17 (protéines, glucides), 37 (lipides), 8 (fibres), 29 (alcool).
Polyols : −7 = 10 − 17, car les glucides incluent déjà les polyols.
Les résidus pointent les protéines végétales : avec la colonne N × 6,25 (celle du règlement), RMSE divisée par plus de 2.
ColinéaritéAjouter l'eau : R² inchangé, mais coefficients méconnaissables (protéines ≈ 9 au lieu de 17) et instables (écart type ≈ 6 kJ/g d'un échantillon à l'autre), conditionnement de XTX × 1000. Car eau ≈ 100 − somme des autres. Aucune corrélation deux à deux n'est proche de ±1 : la redondance porte sur une somme. Remède : retirer la variable redondante, ou régulariser.
Corrélation faible ≠ variable inutileProtéines et énergie sont peu corrélées, pourtant les protéines valent 17 kJ/g : la régression multiple isole l'effet « toutes choses égales par ailleurs ».

5. Au-delà du linéaire

  • Le modèle doit être linéaire en μ, pas en x : on crée des colonnes hj(x) (x², produits…).
  • Transformer la sortie par u inversible : on prédit ẑ = u(y), puis ŷ = u−1(ẑ) (√ → carré ; log → exp, TD 3).
  • Variables retardées (shift) pour une série temporelle ; découpage chronologique.
  • Régression polynomiale de degré q (hyperparamètre) : erreur d'apprentissage toujours décroissante, erreur de test en creux. q = 1 : sous-apprentissage ; q = 15 : sur-apprentissage (R² de test très négatif).
  • Pipeline : PolynomialFeatures → StandardScaler → régression (puissances mal conditionnées sinon).

Toujours standardiser avant (la pénalité dépend des unités). Le Lasso élimine d'abord les constituants rares (acides organiques, polyols). Ridge stabilise un modèle colinéaire mais ne retrouve pas de « vrais » coefficients : il ne remplace pas la réflexion sur les variables.

7. K plus proches voisins

ŷ(x) = moyenne des yi des K exemples les plus proches de x

  • Non paramétrique : le modèle est la base. K est un hyperparamètre.
  • K = 1 : R² d'apprentissage = 1 (sur-apprentissage) ; K grand : lisse, aplati aux bords.
  • weights="uniform" : escalier ; "distance" (w = 1/d) : passe par chaque point ; noyau gaussien w = exp(−d²/2h²) : lisse, réglé par la largeur h.
  • Standardiser : le sodium en mg domine la distance (R² 0,98 → 0,90 sans standardisation).
Limites du KNN
  • Beaucoup d'hyperparamètres (K, pondération, h, distance).
  • Toute la base en mémoire ; prédiction ≈ P × N opérations.
  • Sensible aux unités et aux variables inutiles.
  • Se dégrade en grande dimension (fléau de la dimension).
  • N'extrapole pas, ne s'interprète pas, ne gère pas les manquants.
Méthode générale Comprendre la source → vérifier les types → convertir → étudier les manquants → contrôler la cohérence → visualiser → résumer → séparer apprentissage / test (et validation pour les hyperparamètres) → ajuster → analyser les résidus → corriger avec la connaissance du domaine.
